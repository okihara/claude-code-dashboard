# 🛰 Claude Code ダッシュボード

複数プロセスで並走している Claude Code セッションを 1 画面で俯瞰するローカルダッシュボード。
`~/.claude/projects/**/*.jsonl`（セッション履歴）と `ps`（稼働プロセス）を読み取り、
3秒ごとに自動更新します。**依存パッケージゼロ・Node 単体で動作。**

## 起動

```bash
node server.mjs
# → http://localhost:4317 をブラウザで開く
```

ポートを変えたい場合: `PORT=8080 node server.mjs`

## 画面に出るもの

- **ヘッダーの集計**: 稼働中🟢 / 待機中🟡 / 休眠⚪ のセッション数、稼働プロセス数
- **セッションカード**（新しい順・状態でグループ化）
  - プロジェクト名 / 最終活動からの経過時間
  - セッションタイトル（Claude が付けた `aiTitle`）
  - Git ブランチ・モデル・メッセージ数・`resumed`・`LIVE` バッジ
  - **最後の指示**（ユーザーが投げた最新プロンプト）
  - 直近のやりとりの要約（ツール使用は 🔧 表示）
  - 作業ディレクトリ(cwd)
- 「休眠を隠す」チェックでアクティブなものだけに絞り込み

## 状態の判定（mtime ベース）

| 状態 | 条件 |
|------|------|
| 🟢 稼働中 | セッションファイルが 90 秒以内に更新 |
| 🟡 待機中 | 30 分以内に更新 |
| ⚪ 休眠 | それ以前 |

36時間以内のセッションのみ詳細解析（タイトル・指示・やりとり）し、
それより古いものはメタ情報のみの軽量表示にしています。

## 構成

- `server.mjs` — HTTP サーバ + 解析ロジック。`/api/sessions` で JSON を返す
- `public/index.html` — ダッシュボード UI（自動更新）

## 仕組みのメモ

- 大きな jsonl はファイル末尾（256KB）中心に読むため、件数が多くても高速
- 稼働プロセスは `ps` から native-binary の `claude` を抽出。`--resume <id>` が付いている
  ものは該当セッションに `resumed` バッジを付与
